# Case Management Workbench — clickable prototype (brief v4 · data v3)

Single-file prototype of a nurse case manager's workbench (HiLabs APM caselet). Synthetic data only — no real PHI. Live copy: https://vin1764.github.io/HiLabs_Prototype/

**Open it:** double-click `index.html` (no server, no build). Every value on screen is read from `workbench_state.json`, embedded verbatim in the `<script id="state">` block. Routes: `#queue`, `#member/<id>`, `#outreach/<id>`, `#audit`. The only Confirm buttons are on the outreach screen, after an attempt is logged as *Reached*; every confirmation lands in the audit drawer.
